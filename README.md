# Session Alert

A tiny Mac menu bar app for musicians who share Logic Pro projects over iCloud Drive.
When you open a project, Session Alert texts your collaborator which song you're in.
When you close it, they get an "all yours" text, so you never work on the same song at the same time.

## Install

1. Download the latest `Session-Alert-x.y.zip` from [**Releases**](../../releases/latest) and unzip it.
2. Drag **Session Alert** into your **Applications** folder and open it.
   A music-note house icon appears in the menu bar.
3. **Allow Accessibility access** when asked (System Settings › Privacy & Security › Accessibility),
   then quit and reopen Session Alert. This lets it read which song Logic has open.
4. Click the menu bar icon › **Settings…** and enter:
   - your collaborator's name and phone number or iMessage email
   - your name as it should appear in the texts
   - turn on **Launch Session Alert at login**
5. Click **Send Test**, then **OK** when macOS asks to let Session Alert control Messages.

Requirements: macOS 14 or later, signed in to Messages. For SMS (non-iPhone) recipients,
your iPhone needs Settings › Messages › Text Message Forwarding turned on for your Mac.

Both collaborators should install it so the alerts go both ways.
